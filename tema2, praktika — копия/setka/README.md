# Сетка — утилита для автоматической генерации расписания занятий

## Исполнители

Валиуллина Эмилия, Абибулаева Алина

## Описание

Заведующая отделением собирает недельное расписание из заявок преподавателей.
Заявки приходят текстом и таблицами, а конфликты (преподаватель в двух аудиториях,
группа на двух парах) обнаруживаются уже после публикации.

Сетка решает эту проблему: утилита читает файл заявок, строит сетку на неделю
и показывает конфликты, которые не удалось разрешить, вместе с причиной.

### Возможности

- чтение входного CSV: преподаватель, группа, дисциплина, тип занятия, пар в неделю, требуемая аудитория;
- строгий разбор с указанием номера строки и характера ошибки;
- сетка 6 дней × 5 пар (понедельник–суббота);
- проверка трёх видов конфликтов: преподаватель, группа, аудитория;
- вывод сетки в консоль и в файл (CSV или TXT);
- отчёт о заявках, которые не удалось разместить, с причиной;
- детерминированный результат: одинаковый при повторном запуске на том же файле.

## Стек

- Python 3.11+ (только стандартная библиотека: `csv`, `dataclasses`, `json`);
- pytest для тестов;
- Docker: Dockerfile и compose.yaml, входные и выходные CSV — в томе `./data`.
